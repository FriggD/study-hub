# Contribuindo para o StudyHub

Obrigado por considerar contribuir com o StudyHub! 🎉

## Como Contribuir

### Reportando Bugs

Se você encontrou um bug, por favor abra uma issue incluindo:
- Descrição clara do problema
- Passos para reproduzir
- Comportamento esperado vs. atual
- Screenshots (se aplicável)
- Ambiente (navegador, SO, versão)

### Sugerindo Funcionalidades

Para sugerir novas funcionalidades:
1. Verifique se já não existe uma issue similar
2. Abra uma nova issue com a tag `enhancement`
3. Descreva claramente a funcionalidade e seu valor
4. Explique casos de uso

### Submetendo Pull Requests

1. **Fork** o repositório
2. **Clone** seu fork localmente
3. **Crie uma branch** para sua contribuição:
   ```bash
   git checkout -b feature/minha-funcionalidade
   ```
4. **Faça suas alterações** seguindo as diretrizes de código
5. **Commit** suas mudanças com mensagens claras:
   ```bash
   git commit -m "feat: adiciona nova funcionalidade X"
   ```
6. **Push** para sua branch:
   ```bash
   git push origin feature/minha-funcionalidade
   ```
7. **Abra um Pull Request** na branch principal

## Diretrizes de Código

### Geral
- Mantenha o código limpo e legível
- Adicione comentários quando necessário
- Siga os padrões existentes no projeto
- Escreva testes para novas funcionalidades (TODO: definir framework)

### Commits
Siga o padrão de [Conventional Commits](https://www.conventionalcommits.org/):

- `feat:` Nova funcionalidade
- `fix:` Correção de bug
- `docs:` Mudanças na documentação
- `style:` Formatação, sem mudança de código
- `refactor:` Refatoração de código
- `test:` Adição ou modificação de testes
- `chore:` Tarefas de manutenção

**Exemplos:**
```
feat: adiciona sistema de flashcards
fix: corrige erro ao salvar notas Cornell
docs: atualiza instruções de instalação
```

## Revisão de Código

Todos os PRs passam por revisão. Esperamos:
- Código que segue as diretrizes do projeto
- Testes adequados (quando aplicável)
- Documentação atualizada
- Commits organizados e descritivos

## Código de Conduta

### Nosso Compromisso

Estamos comprometidos em fazer da participação neste projeto uma experiência livre de assédio para todos.

### Comportamento Esperado

- Use linguagem acolhedora e inclusiva
- Respeite pontos de vista diferentes
- Aceite críticas construtivas
- Foque no que é melhor para a comunidade
- Mostre empatia com outros membros

### Comportamento Inaceitável

- Uso de linguagem ou imagens sexualizadas
- Comentários insultuosos ou depreciativos
- Assédio público ou privado
- Publicação de informações privadas sem permissão
- Outras condutas não profissionais
