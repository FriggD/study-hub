# StudyHub

StudyHub é um hub de estudos que centraliza métodos como Cornell, mapas mentais e flashcards, unindo organização, aprendizado ativo e gamificação saudável para incentivar constância, foco e melhor retenção de conhecimento.

## 📚 Visão Geral

O StudyHub tem como objetivo fornecer uma plataforma integrada para estudantes que desejam melhorar sua organização e retenção de conhecimento através de métodos comprovados de aprendizagem.
